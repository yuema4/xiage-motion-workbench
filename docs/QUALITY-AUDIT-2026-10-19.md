# 动效质量排查 2026-10-19

## 已确认的问题

1. 文案格式不匹配：此前 JSON 的五角色清单用竖线放在一行。WorkflowActionListCard 按换行取前三项，不足三行时显示无关的默认文案；即便正确传五行仍截成三项。这是卡片协议和生成端不一致，不是用户操作问题。
2. 时间与语义错位：52张规划按整四秒网格生成，完整流水线原文为152.566-155.100秒，卡片却放在156-160秒；不依赖本地开机原文180.533-182.366秒，卡片放在184-188秒。15张/分钟应该控制数量，不能取代字幕对齐。
3. 短语未提炼：多张高亮卡塞入完整口语句，不是1-3个重点短语。高频长句带来阅读负担。
4. 放大被边界抵消：calculateCardScale 按中心锚点与预估高度限制缩放。1920×1080、y=16、基高620时上限约0.528，设置0.54并不会得到0.54。更高卡片还会更小。
5. 版本与用户项目混在一起：App在cardLibrarySignature不匹配时删除已保存项目并恢复默认卡库。升级视觉实现不应该清掉用户已编排内容。需先加入缓存备份和迁移再调整，不能直接破坏当前项目。
6. 规则文档相互矛盾：同一文档既要求硬切又要求淡出，既要求全用高亮卡又要求数字自动选专用卡；本次已在规则前部写明用户最新选卡约束，历史规则需分开归档。
7. 启动器构建失败会退回旧dist；render-overlay只检查3188上版本文件返回成功，不核对签名。源码修改不能代表运行版或导出已更新。
