# 夏哥视效工作台

定位用户下载的仓库，先读 CLAUDE.md、README.md 和 docs/ACCEPTANCE.md。不要假设个人路径、依赖已安装或导出功能已实现。

## 使用

macOS + Node.js 22，运行仓库根目录 `bash start.command`。运行目录避开 iCloud，使用终端返回的本机地址，不停止其他项目的服务。
上传口播视频、选画幅、导入字幕或 JSON、检查动态预览、编辑文字/位置/颜色并导出 JSON。重开后可能需要重新选择视频。

## 字幕编排

1. 读取完整 SRT，校验时间、合并同一语义的连续字幕，跳过纯英文、重复和低信息句。
2. 先列时间、原文、重点、建议卡片、是否制作及原因的规划表，目标每分钟 10–15 张，不凑数。
3. 默认重点短语高亮；明确百分比用百分比卡，流程用步骤卡，数字用数字卡，不虚构数据。
4. 读取 app/src/types.ts、app/src/data/effectRegistry.ts、app/src/data/effectTemplates.ts 和 sampleProject.ts 获取实际字段与 ID，不发明卡片。
5. 检查人物、字幕和画框边界；自动安全区不是人物检测保证。

## 交付模式

普通叠加可另行制作透明 ProRes 4444 MOV，真实 Alpha、无声、原片对齐、结束硬切不留彩色残影。
分屏先做语义分镜和关键帧，确认后制作演示，最终交付完整 MP4：原口播及声音、右侧演示、选定背景、外框与文字品牌；覆盖完整原片，演示默认静音，不伪造真实网页操作。
试用包没有上述视频合成器，不把说明当成可执行按钮。缺少工具时说明限制，不声称已导出。

## 制作和扩展

React + TypeScript + Vite；预览与渲染共用组件。先定稳定 ID、内容字段、设计尺寸、语义与布局规范，再接入注册表、模板和组件。
时间轴确定性驱动动画，文字可编辑、完整可读。参考图不自动赋予人物、商标与素材的分发权。
修改后构建，在真实工作台点击添加、编辑、拖动播放头并检查横竖屏；截图必须来自实际工作台。未经用户同意不公开仓库。
