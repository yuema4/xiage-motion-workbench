# 夏哥视效工作台 · 私有试用版

本地视频动效工作台与配套 AI Skill。视频由浏览器读取，不默认上传到服务器。

## 启动（macOS）

安装 Node.js 22 LTS 或更新版本，把仓库下载到非 iCloud 目录，例如 `~/Developer/xiage-motion-workbench`。
在仓库目录运行 `bash start.command`，首次会联网安装依赖、编译并打开浏览器。
保持终端打开，结束时按 Control+C。后续仍使用同一命令。
这是源代码试用包，暂未提供签名桌面安装器。

## 使用

上传口播 → 选择画幅 → 导入中文 SRT 或 JSON → 检查安全区和时间轴 → 编辑卡片 → 导出 JSON 保存。
独立分屏支持两路视频预览、背景和人物占比。暂不承诺一键视频合成。
启动使用空闲端口，不占用其他工作台；端口变化时浏览器存储不共享，务必导出 JSON，重开时重新导入并选择视频。

## 配套 Skill

把 `skills/xiage-motion-workbench` 安装到 AI 工具支持的 Skills 目录，告诉 AI 本仓库的位置；也可以直接让 AI 阅读其中的 SKILL.md。
Skill 教安装、使用、语义编排和扩展，不包含模型服务或账号。将素材发给云端 AI 前请确认数据政策。

## 试用边界

- APP 背后环绕依赖的商标素材和分割模型许可尚未核实，此版本停用该入口，个人版不受影响。
- 未随包提供透明 MOV 渲染器或分屏完整 MP4 合成器；JSON 是编排文件，不是视频。
- 长文字、自动安全区和各画幅需按实际素材检查，不保证所有卡片自动避开人物。
- 仅限获邀私有试用，未授予公开再分发或商业许可。第三方依赖仍受原许可证约束。
